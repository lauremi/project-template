# Week 2-3: Frontend Testing

- Verify page layouts match the wireframes
- Test responsive design on different screen sizes
- Check navigation between pages
- Validate form fields and input restrictions
- Review UI consistency (fonts, colors, spacing)

# Week 4-5: Backend & Integration Testing

- Test database connections
- Verify user authentication
- Test login with valid credentials
- Test login with invalid credentials
- Verify error messages are displayed correctly
- Test session handling and logout functionality

# Week 6: System Testing & Bug Fixes

- Execute all test cases from the test plan
- Perform end-to-end login workflow testing
- Cross-browser testing (Chrome, Edge, Firefox, Safari)
- Security checks for authentication
- Regression testing after bug fixes
- Fix any remaining defects

# Week 7: User Acceptance Testing (UAT)
- Final testing by supervisor, client, or end users
- Verify all requirements are met
- Record any final issues
- Obtain project approval before deployment
