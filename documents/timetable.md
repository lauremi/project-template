## Project Schedule

**Project Period:** 25.09.2026 - 12.11.2026

### Project Goal
Develop a secure web application that allows users to authenticate through an ASP.NET API, access a personal dashboard, and store persistent user data in a SQL Server database.

---

# Week 1: Planning & Design
Define requirements and functionality
Create wireframes for:
- Login page
- Dashboard

- Choose color palette, fonts, and visual style
- Plan database structure and user authentication flow

# Weeks 2-3: Frontend Development
- Build login page UI
- Build landing page UI
- Implement responsive design
- Add form validation and error messages
- Test layout across different screen sizes and browsers

# Weeks 4-5: Backend & Database Development
- Set up database
- Create user tables and authentication logic
- Implement login functionality
- Connect frontend to backend
- Handle session management and security measures

# Week 6: Testing & Bug Fixes
- Functional testing
- Login and authentication testing
- Error handling testing
- Cross-browser testing
- Fix identified bugs and usability issues

# Week 7: Deployment & Documentation
- Deploy website to hosting environment
- Perform final acceptance testing
- Create technical documentation
- Create user documentation if required
- Project review and handover
